# 03. 디자인

## 원칙
- 남은 시간이 화면에서 가장 크게, 멀리서도 읽힘
- 한 화면에 전부 표시 (스크롤 없음, 페이지 이동 없음)
- 설정은 접어 두고 필요할 때만 펼침
- 외형은 **Liquid Glass** 스타일: 색이 번진 배경 위에 반투명 유리 패널을 겹치고, 조작 요소는 둥근 알약 모양으로 통일

## Liquid Glass 스타일 규칙

| 요소 | 처리 |
|---|---|
| 배경 | 연한 그라데이션 위에 보라·민트·살구·하늘색 **색 번짐(blob)** 4개를 크게 흐려서(blur 70px) 배치. 천천히 떠다니는 애니메이션 (26~36초 주기) |
| 유리 패널(`.card`) | 반투명 흰색(라이트 10% / 다크 어두운 남색 30%) + `backdrop-filter: blur(24px) saturate(1.6)`. 테두리는 밝은 반투명 흰색 1px, 위쪽 안쪽에 1px 광택선, 왼쪽 위에서 비스듬히 내려오는 광택 그라데이션, 보랏빛 부드러운 그림자 |
| 남은 시간 슬래브(`.dial`) | 패널 안의 두 번째 유리층. 모서리 28px, 안쪽에 상태 색(보라·민트 / 강조 시 산호색)이 은은하게 비침 |
| 버튼 | 알약 모양(`border-radius: 999px`). 주 버튼은 보라 그라데이션 + 보랏빛 그림자 + 위쪽 광택, 보조 버튼은 민트 유리, 알람 정지는 산호색 그라데이션 |
| 빠른 설정 칩·모드 탭·입력칸·스위치 | 모두 같은 유리 재질(반투명 흰색 + 밝은 테두리 + 위쪽 광택선). 선택·켜짐 상태만 보라 그라데이션 또는 더 불투명한 흰색 |
| 눈금 | 켜진 눈금은 보라→민트(강조 시 산호→살구) 그라데이션 선 + 약한 글로우. 꺼진 눈금은 회색 |
| 둥글기 | 패널 32px / 슬래브 28px / 입력칸 16px / 버튼·칩·탭 알약 |

- `backdrop-filter`를 지원하지 않는 브라우저와 OS의 "투명도 줄이기" 설정에서는 패널을 더 불투명하게 표시
- "애니메이션 줄이기" 설정에서는 배경 색 번짐이 움직이지 않음

## 화면 구성

```
┌─────────────────────────────────────────┐
│        [ 시간 지정 ][ 종료 시각 ]     [⚙] │  ← 모드 탭 / 설정(톱니바퀴 아이콘만)
│   ╭┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╮   │  ← 테두리 눈금 (남은 시간 비율)
│   ┆             25:00              ┆   │  ← 남은 시간 (가장 크게)
│   ┆          14:35:20 종료          ┆   │  ← 보조 정보
│   ╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯   │
│                                         │
│   [ 분 ] : [ 초 ]                        │  ← 시간 지정 모드 입력
│ (1분)(2분)(3분)(4분)(5분)(10분)(15분)(30분) │  ← 빠른 설정
│                                         │
│        [ 시작 ]      [ 초기화 ]           │
├─────────────────────────────────────────┤
│ 설정 (펼쳤을 때)                          │
│  소리          [on/off]   볼륨 ──●──     │
│  화면 깜빡임    [on/off]   [소리 테스트]  │
│  탭 제목 깜빡임 [on/off]                  │
│  데스크톱 알림  [on/off]                  │
└─────────────────────────────────────────┘
```

종료 시각 모드에서는 입력 영역이 아래처럼 바뀜:

```
│   종료 시각  [ 15 ]시 : [ 05 ]분           │
│                                         │  ← 빈 줄 (버튼 위치 맞춤)
```

## 테두리 눈금
- 남은 시간·보조 정보를 모서리가 살짝 둥근 사각형 모양의 짧은 눈금들이 둘러쌈
- 눈금은 테두리 둘레를 따라 같은 간격(약 11px), 테두리에 수직 방향
- **위쪽 가운데에서 시작해 시계 방향**으로, 남은 시간 비율만큼 눈금이 켜짐
  - 시작 시 전부 켜짐 → 시간이 지날수록 켜진 구간의 끝이 위쪽 가운데 쪽으로 줄어듦
  - 경계 눈금은 서서히 꺼짐 (뚝뚝 끊기지 않게)
- 꺼진 눈금은 회색이며, 경계에서 멀어질수록 옅어짐
- 켜진 눈금은 SVG `<linearGradient>`(dial.js에서 생성, 색은 CSS 변수)로 칠함
- 상태별 색: 진행 중 보라→민트 그라데이션 / 마지막 10초·알람 산호→살구 그라데이션 / 일시정지 흐리게 점멸 / 시간 미입력 전부 옅은 회색
- 창 크기가 바뀌면 눈금 개수를 다시 계산

## 상태별 화면

| 상태 | 남은 시간 표시 | 버튼 | 기타 |
|---|---|---|---|
| 대기 (시간 지정) | 입력값 표시, 기본 색 | 시작, 초기화(비활성) | 입력칸 활성 |
| 대기 (종료 시각) | 미리보기, **흐리게 + 천천히 점멸** (일시정지와 같은 효과) | 시작, 초기화(비활성) | 입력칸 활성 |
| 진행 중 | 기본 색 | 일시정지, 초기화 | 입력칸 비활성 (모드 탭·빠른 설정은 누를 수 있음, 누르면 초기화) |
| 일시정지 | 흐리게 + 천천히 점멸 | 재개, 초기화 | |
| 마지막 10초 | 강조 색 | 동일 | |
| 종료(알람) | 강조 색, `00:00` | **알람 정지** (강조 색), 초기화 | 화면 깜빡임 |

- 두 버튼은 너비 120px로 고정하고 항상 표시 → 상태·모드가 바뀌어도 위치가 움직이지 않음
- 종료 시각 모드는 입력칸 아래에 빠른 설정 버튼 줄과 같은 높이의 빈 줄을 둠
- 종료 시각 모드의 보조 정보: `21:00 종료(1시간 후)`

## 색상

라이트/다크 모드 모두 지원. Windows 설정(`prefers-color-scheme`)을 따름.

| 용도 | 라이트 | 다크 |
|---|---|---|
| 배경 그라데이션 | `#eef0fb` → `#dfe6f0` | `#121327` → `#0b0e1a` |
| 색 번짐 (보라 / 민트 / 살구 / 하늘) | `#8e7cff` / `#60e0d0` / `#ffb0a0` / `#8cc4ff` (반투명) | 같은 색, 더 어둡고 낮은 투명도 |
| 유리 패널 | `rgba(255,255,255,0.1)` | `rgba(34,36,58,0.3)` |
| 유리 테두리 | `rgba(255,255,255,0.4)` | `rgba(255,255,255,0.16)` |
| 기본 글자 | `#1c1b2e` | `#f3f2fb` |
| 보조 글자 | `#6a6880` | `#a3a2bd` |
| 주 색상(보라: 시작 버튼, 켜진 스위치, 눈금) | `#7b6cf4` (`#9d8cff` → `#6555e6`) | `#8f80ff` (`#b3a6ff` → `#6f5ff0`) |
| 보조 색상(민트: 초기화 버튼, 눈금 끝) | `#5fd8c9` | `#5ee0d0` |
| 강조(산호: 마지막 10초, 알람) | `#ef5f6b` (`#ff8a7a` →) | `#ff6b76` (`#ff9a86` →) |
| 꺼진 눈금 | `#8f8da8` | `#6c6b88` |

CSS 변수(`--glass`, `--glass-border`, `--accent`, `--mint`, `--alert`, `--highlight` 등)로 정의해 한 곳에서 수정.

## 글꼴
- 기본: 시스템 글꼴 (`system-ui`, Windows에서는 맑은 고딕 / Segoe UI)
- 숫자: 숫자 폭이 고정된 표시 사용 (`font-variant-numeric: tabular-nums`)
  - 숫자가 바뀔 때 글자가 좌우로 흔들리지 않게
- 남은 시간 크기: 화면 폭에 비례 (`clamp(48px, 13vw, 120px)`)
- 남은 시간 글자에 약한 그림자(라이트: 흰색 1px 하이라이트, 다크: 보랏빛 글로우)를 넣어 유리 위에서도 또렷하게 보이게 함

## 깜빡임 규칙
- 화면 깜빡임: 배경을 강조 색 ↔ 기본 배경으로 **1초에 1회** 전환
  - 광과민성 발작 예방 기준(초당 3회 이하)을 지킴
  - 화면 전체를 원색으로 채우기보다 배경에 반투명 강조 색을 덮는 방식
- 탭 제목 깜빡임: 1초 간격
- 운영체제의 "애니메이션 줄이기" 설정이 켜져 있으면 깜빡임 대신 강조 색 고정 표시
