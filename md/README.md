## 개발 전 결정할 사항

아래는 기본값을 정해 두었습니다. 다르게 하고 싶으면 개발 전에 바꾸면 됩니다.

| # | 항목 | 기본값 | 다른 선택지 |
|---|---|---|---|
| D1 | 종료 시각이 현재보다 이전일 때 | **다음 날로 자동 처리** (화면에 "내일" 표시) | 오류 메시지 표시 |
| D2 | 종료 시각 입력 형식 | **24시간제** `HH:MM` | 오전/오후 선택 |
| D3 | 종료 시각 모드에서 일시정지 | **허용** (재개 시 남은 시간 기준으로 동작, 종료 시각이 밀림) | 허용 안 함 (초기화만 가능) |
| D4 | 알람 소리 | **코드로 만든 비프음** (파일 불필요) | mp3 파일 사용 |
| D5 | 알람 지속 시간 | **정지할 때까지 반복, 최대 60초 후 자동 정지** | 1회만 울림 / 무한 반복 |
| D6 | 새로고침 시 진행 중이던 타이머 | **복구** | 초기화 |
| D7 | 즉석 설정 단위 | **분 + 초** 입력 | 분만 입력 |
