# 02. 기능 명세

## F1. 시간 지정 카운트다운 (즉석 설정)

- 입력: **분**, **초** 두 칸 (기본값: 마지막으로 사용한 시간)
  - 분: 0 ~ 999, 초: 0 ~ 59
  - 0분 0초는 시작 불가 (시작 버튼 비활성)
- 빠른 설정 버튼: `1분` `2분` `3분` `4분` `5분` `10분` `15분` `30분`
  - 누르면 입력칸에 값만 들어가고 **자동으로 시작하지 않음** (시작 버튼 또는 `Space`로 시작)
  - 타이머 진행 중·일시정지 중·알람 중에도 누를 수 있으며, 이 경우 **기존 타이머를 초기화**한 뒤 값을 넣음
- 입력칸에서 `Enter` → 시작

## F2. 종료 시각 지정 카운트다운

- 입력: 종료 시각 `시`(0~23) · `분`(0~59) 두 칸 (24시간제)
  - 브라우저 기본 시각 입력칸은 Windows 설정에 따라 오전/오후로 표시되므로 숫자 칸 두 개로 받는다
- 시작하면 `종료 시각 - 현재 시각`으로 남은 시간을 계산해 카운트다운
  - 예: 현재 13:20, 입력 15:05 → 1시간 45분 카운트다운
- 입력한 시각이 현재보다 이전이거나 같으면 **다음 날 같은 시각**으로 처리
  - 화면에 `내일 07:00 종료` 처럼 표시해 착각 방지
- 남은 시간 아래 보조 정보를 `21:00 종료(1시간 후)` 형식으로 표시 (시작 전·진행 중 모두)
  - 남은 시간은 분 단위 올림: `1시간 후`, `1시간 45분 후`, `45분 후`
  - 다음 날이면 `내일 07:00 종료(9시간 30분 후)`
  - 일시정지 후 재개해 종료 시각이 초 단위로 밀리면 초까지 표시: `21:00:05 종료(59분 후)`
- 시작 전에는 남은 시간이 미리보기로 표시되며, 일시정지 상태와 같은 흐린 점멸 효과로 표시 (아직 시작 안 됨을 구분)
- 일시정지 가능. 재개하면 남은 시간 기준으로 이어서 진행하므로 **종료 시각이 멈춘 시간만큼 밀림** — README의 D3 참고
- 초 단위는 0초 기준 (15:05 입력 → 15:05:00에 알람)

## F3. 타이머 조작

| 상태 | 가능한 조작 |
|---|---|
| 대기 | 시작 (초기화는 비활성) |
| 진행 중 | 일시정지, 초기화 |
| 일시정지 | 재개, 초기화 |
| 종료(알람 중) | 알람 정지, 초기화 |

- 버튼은 두 개(`시작/일시정지/재개/알람 정지`, `초기화`)가 **항상 같은 자리·같은 크기**로 표시되고 글자만 바뀜
  - 모드를 바꿔도 버튼 위치는 같음

- 진행 중에는 입력칸(분·초, 시·분) 비활성화
- 모드 탭(`시간 지정` / `종료 시각`)은 항상 누를 수 있음
  - 진행 중·일시정지 중·알람 중에 **다른 모드**를 누르면 기존 타이머를 초기화하고 모드 전환
  - 현재 모드 탭을 다시 누르면 아무 변화 없음
- 알람을 정지하면 대기 상태로 돌아가고, 직전 설정값은 입력칸에 유지

### 키보드 단축키
화면에 단축키 설명은 표시하지 않는다.

| 키 | 동작 |
|---|---|
| `Space` | 시작 / 일시정지 / 재개 (입력칸에 포커스가 있을 때는 동작 안 함) |
| `Enter` | 입력칸에서 시작 |

## F4. 남은 시간 표시

- 메인 표시: `HH:MM:SS` (1시간 미만이면 `MM:SS`)
- 보조 표시: 종료 예정 시각 `14:35:20 종료`
- 테두리 눈금: 남은 시간 둘레의 둥근 사각형 눈금이 남은 비율만큼 켜짐 (03_design.md 참고)
- **브라우저 탭 제목**에 남은 시간 표시: `12:34 - 타이머`
  - 다른 탭을 보고 있어도 남은 시간 확인 가능

## F5. 종료 알림

각 항목은 설정에서 개별 on/off.

| 알림 | 기본값 | 동작 |
|---|---|---|
| 소리 | on | 비프음 반복. 알람 정지 또는 60초 경과 시 멈춤 |
| 화면 깜빡임 | on | 화면 배경이 깜빡임. 알람 정지 시 멈춤 |
| 탭 제목 깜빡임 | on | 탭 제목이 `⏰ 시간 종료!` ↔ `타이머` 로 번갈아 바뀜 |
| 데스크톱 알림 | off | Windows 알림 표시. 처음 켤 때 브라우저 권한 요청 |

- 볼륨 슬라이더 (0 ~ 100%)
- `소리 테스트` 버튼
- 알람 정지 방법: `알람 정지` 버튼, `Space`, 화면 아무 곳 클릭

## F6. 설정 저장

localStorage에 자동 저장. 별도 저장 버튼 없음.

| 저장 항목 | 설명 |
|---|---|
| 알림 on/off 4종 | F5 |
| 볼륨 | F5 |
| 마지막 사용 시간 (분·초) | 다음 접속 시 입력칸 기본값 |
| 마지막 입력 종료 시각 | 다음 접속 시 입력칸 기본값 |
| 마지막 사용 모드 | 시간 지정 / 종료 시각 |

## F7. 새로고침·재접속 시 복구

- 진행 중 상태(종료 시각, 모드 등)를 localStorage에 저장
- 페이지를 다시 열었을 때
  - 아직 종료 전이면 → 이어서 카운트다운
  - 그 사이 종료 시각이 지났으면 → 알람 없이 `HH:MM에 종료됨` 안내 후 대기 상태
- 일시정지 상태도 복구
