# 01. 프로젝트 개요

## 목적
PC 브라우저에서 바로 열어 쓰는 개인용 카운트다운 타이머.
- 필요할 때 즉석으로 n분을 설정해 카운트다운
- 알람이 울릴 **시각**을 입력하면 남은 시간을 자동 계산해 카운트다운
- 종료 시 소리·화면 깜빡임으로 알림, 각 알림은 켜고 끌 수 있음

## 사용 환경
| 항목 | 내용 |
|---|---|
| 사용자 | 본인 1명 |
| 기기 | Windows PC |
| 브라우저 | Chrome / Edge 최신 버전 기준 (Firefox는 가능하면 지원) |
| 화면 | 데스크톱 해상도 기준. 브라우저 창을 작게 띄워 두고 쓰는 경우도 고려 (최소 폭 약 360px) |

## 범위

### 포함
- 시간(분·초) 지정 카운트다운
- 종료 시각 지정 카운트다운
- 시작 / 일시정지 / 재개 / 초기화
- 알림: 소리, 화면 깜빡임, 탭 제목 깜빡임, (선택) 데스크톱 알림
- 알림 종류별 on/off, 볼륨
- 설정 자동 저장 (브라우저 localStorage)
- 새로고침 시 진행 중 타이머 복구

### 제외
- 로그인, 기기 간 동기화
- 서버, 데이터베이스
- 모바일 최적화
- 여러 타이머 동시 실행
- 스톱워치, 뽀모도로 등 다른 모드

## 기술 스택
| 영역 | 선택 | 비고 |
|---|---|---|
| 마크업 | HTML | |
| 스타일 | CSS (프레임워크 없음) | |
| 로직 | JavaScript (바닐라, 빌드 도구 없음) | |
| 저장 | localStorage | 브라우저에만 저장 |
| 소리 | Web Audio API | 파일 없이 비프음 생성 |
| 호스팅 | GitHub Pages | 무료, HTTPS 기본 제공 |

라이브러리, npm, 빌드 과정 없이 파일만 올리면 동작하는 구조로 만든다.
