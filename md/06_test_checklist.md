# 06. 테스트 체크리스트

개발 후 Chrome(또는 Edge)에서 직접 확인.

## 시간 지정 카운트다운 (F1)
- [ ] 분·초 입력 후 시작 → 정확히 카운트다운
- [ ] 0분 0초면 시작 버튼 비활성
- [ ] 초에 60 이상, 음수, 문자 입력 시 막히거나 보정됨
- [ ] 빠른 설정 버튼 → 입력칸에 값만 들어가고 시작하지 않음
- [ ] 진행 중 빠른 설정 버튼 → 기존 타이머 초기화 후 값 입력
- [ ] 진행 중 다른 모드 탭 → 기존 타이머 초기화 후 모드 전환
- [ ] 진행 중 현재 모드 탭 → 아무 변화 없음
- [ ] 알람 중 빠른 설정 / 모드 탭 → 알람 꺼지고 해당 동작 수행
- [ ] 입력칸에서 Enter → 시작

## 종료 시각 카운트다운 (F2)
- [ ] 현재보다 이후 시각 입력 → 남은 시간 정확
- [ ] 현재보다 이전 시각 입력 → 다음 날로 처리, `내일` 표시
- [ ] 보조 정보가 `21:00 종료(1시간 후)` 형식으로 표시되고 입력·진행에 따라 갱신
- [ ] 정확히 입력한 시각(00초)에 알람
- [ ] 자정 넘어가는 경우 (예: 23:50에 00:10 입력 → 20분)
- [ ] 시작 전에는 남은 시간·눈금이 흐리게 점멸
- [ ] 일시정지 → 재개 시 종료 시각이 멈춘 시간만큼 밀림

## 조작 (F3)
- [ ] 일시정지 → 시간 멈춤, 재개 → 이어서 진행
- [ ] 대기·진행·일시정지·알람, 두 모드 모두에서 두 버튼 위치가 같음
- [ ] 대기 중 초기화 버튼은 보이지만 비활성
- [ ] 초기화 → 대기 상태, 입력값 유지
- [ ] Space 단축키 동작
- [ ] 입력칸에 커서가 있을 때 Space는 타이머를 건드리지 않음

## 표시 (F4)
- [ ] 1시간 이상일 때 `HH:MM:SS`, 미만일 때 `MM:SS`
- [ ] 탭 제목에 남은 시간 표시
- [ ] 테두리 눈금이 남은 비율만큼 켜져 있고, 위쪽 가운데 방향으로 줄어듦
- [ ] 마지막 10초·알람 때 눈금이 빨간색, 일시정지 때 흐리게 점멸
- [ ] 창 크기를 바꿔도 눈금이 테두리에 맞게 다시 그려짐
- [ ] 마지막 10초 강조 색

## 알림 (F5)
- [ ] 소리 on → 울림 / off → 안 울림
- [ ] 화면 깜빡임 on/off
- [ ] 탭 제목 깜빡임 on/off
- [ ] 데스크톱 알림: 켤 때 권한 요청, 허용 시 Windows 알림 표시
- [ ] 볼륨 조절, 소리 테스트 버튼
- [ ] 알람 정지 (버튼 / Space / 클릭)
- [ ] 60초 후 소리 자동 정지

## 저장·복구 (F6, F7)
- [ ] 설정 변경 후 새로고침 → 설정 유지
- [ ] 마지막 사용 시간이 입력칸 기본값으로 표시
- [ ] 진행 중 새로고침 → 이어서 카운트다운
- [ ] 일시정지 중 새로고침 → 일시정지 상태 유지
- [ ] 창을 닫았다가 종료 시각 이후 다시 열기 → `종료됨` 안내
- [ ] 시크릿 창에서도 타이머 자체는 정상 동작

## 백그라운드 (T-BG)
- [ ] 10분 타이머 시작 → 다른 탭으로 전환 → 끝날 때 소리가 제때 울리는지 (오차 몇 초 이내)
- [ ] 브라우저 창 최소화 상태에서도 소리 울리는지
- [ ] 다른 탭에 있다가 돌아왔을 때 남은 시간이 정확한지
